Rail Fence (Keyless) & Columnar Transposition Cipher

Aim

To study how Rail Fence and Columnar transposition ciphers rearrange the positions of characters using an inverse permutation.

Objective

  • Understand the transposition cipher and the idea of an inverse permutation.
  • Observe the zig-zag row arrangement used by the Rail Fence cipher.
  • Study the keyword-based column arrangement used by the Columnar transposition cipher.
  • Use the simulation to produce and interpret ciphertext.

Theory

Transposition Cipher

A transposition cipher changes the order of characters in a message according to a permutation. The character set remains the same, but the positions are rearranged. Applying the inverse permutation restores the original message.

Rail Fence — Keyless

Characters are written in a zig-zag pattern across a user-selected number of rows. The ciphertext is obtained by reading the rows from top to bottom.

Example: HELLOWORLD, 3 rows
Row 1: H   O   L
Row 2:  E L W R D
Row 3:   L   O

Columnar Transposition Cipher

Plaintext is written row-wise beneath a keyword. The columns are assigned ranks by alphabetical order of the keyword letters, then read in rank order to produce the ciphertext. Duplicate key letters are ranked from left to right.

Key: Z E B R A
Order: 5 3 2 4 1

Procedure

Transposition Cipher

In both methods, write the plaintext into an arrangement, apply a position permutation, and read the resulting characters as ciphertext. To recover the plaintext, apply the inverse permutation.

Rail Fence procedure

  1. Enter the plaintext and select the required number of rows.
  2. Write the characters diagonally down and up in a zig-zag pattern across the rows.
  3. Read the characters row by row from top to bottom. This gives the ciphertext.
  4. For recovery, mark the zig-zag positions, place the ciphertext row by row, and read along the zig-zag path.

Example: For HELLOWORLD with 3 rows, reading the arranged rows produces the ciphertext HOLELWRDLO.

Columnar transposition procedure

  1. Enter the plaintext and choose a keyword.
  2. Write the plaintext from left to right in rows under the keyword. Do not add padding to the final row.
  3. Number the keyword letters in alphabetical order from 1 onward. If letters repeat, number them from left to right.
  4. Read each column from top to bottom in increasing rank order. The combined result is the ciphertext.
  5. For recovery, split the ciphertext into the appropriate column lengths, place each part under its ranked keyword column, and read the grid row-wise.

Example: With plaintext ATTACKATDAWN and keyword ZEBRA, the ranked columns are 5 3 2 4 1; reading them in rank order gives the ciphertext CATTTANADAKW.
